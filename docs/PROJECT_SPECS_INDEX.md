# Project Specification Documents

این پوشه باید شامل تمام ۳۷ فایل مشخصات پروژه‌ای باشد که این کد از روی
آن‌ها ساخته می‌شود (Vision، Feature List، Architecture، Database Schema،
API Spec، Sync Engine، Security، Design System، UI/UX، ...، Release
Checklist). فایل‌های اصلی را همان‌طور که به‌من دادید داخل این پوشه کپی
کنید تا هر ابزاری (Claude Code، Cursor، GPT) طبق دستور `29/31/32/33/34`
قبل از نوشتن کد آن‌ها را بخواند.

فهرست فایل‌های مرجع:

01–19: Vision, Master Prompt, PRD, Feature List, Architecture, DB Schema,
API Spec, Sync Engine, Security, Design System, UI/UX, Component Library,
Navigation, Supabase, Edge Functions, Storage, Auth, Product Search, Price
Estimation, AI Integration.

20–38: Testing Strategy, Deployment & Hosting, GitHub Workflow, Roadmap,
README, UI/UX Design System, Migration Strategy, Local DB & Offline Sync,
Test Plan, Final Implementation Prompt, Project Rules, Master Prompt v2,
Claude Code / Cursor / GPT guides, Milestones 1–3, Release Checklist.
